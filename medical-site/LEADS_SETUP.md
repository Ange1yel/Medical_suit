## Настройка Google Apps Script (один раз)
1. Откройте таблицу по ссылке выше под аккаунтом с правами редактирования.
2. Расширения → Apps Script. Замените код в Code.gs содержимым файла `medical-site/google-apps-script/Code.gs`. Сохраните.
3. Нажмите Развернуть → Новое развёртывание → Веб-приложение. Исполнять от имени: **я**. Доступ: **все**. Авторизуйте доступ скрипта к таблице.
4. Скопируйте URL, заканчивающийся на `/exec`, в переменную `LEADS_ENDPOINT` в корневом `script.js` и сохраните изменения в GitHub.
5. Отправьте одну тестовую заявку с сайта и проверьте, что появилась строка на вкладке «Заявки». **Не публикуйте сайт для сбора контактов до этого теста.**
6. Настройте политику конфиденциальности, согласие на обработку персональных данных, срок хранения и контакт владельца сайта перед реальным сбором.

## Telegram (необязательно)
Создайте бота через BotFather, узнайте chat_id. В настройках проекта Apps Script → Script Properties сохраните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Не размещайте токен в репозитории.

## Примечания
- Форма отправляет POST из браузера в режиме `no-cors`: JavaScript не может проверить успешность записи на стороне Google. Поэтому страница не показывает недостоверное «заявка получена».
- Публичный Apps Script допускает обращения посторонних; для серьёзной рекламной кампании лучше серверная защита от спама, ограничение частоты запросов и подтверждение доставки.
- GitHub Pages сам по себе не хранит и не отправляет заявки.
